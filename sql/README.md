# 🛠️ SQL - Nós 3D

> Do modelo no papel ao banco de dados funcionando.

##  O que é esta pasta?

Aqui fica o **projeto físico** do banco de dados do **Nós 3D**, um negócio de impressão 3D que precisava centralizar clientes, pedidos e materiais.

Depois de planejar o negócio (requisitos), desenhar a ideia (MER) e organizar em tabelas (modelo lógico), chega a hora de escrever o código que cria tudo de verdade. É isso que você encontra aqui.

##  O que você vai ver

O código está registrado **do início ao fim**, mostrando o passo a passo de como o banco foi construído:

-  a criação do banco de dados
-  a criação de cada tabela, com suas colunas e tipos de dados
-  as chaves primárias, que identificam cada registro
-  as chaves estrangeiras, que ligam uma tabela à outra
-  as regras de validação, que impedem dados errados

Assim, quem abrir a pasta consegue acompanhar todo o processo, em vez de ver só o resultado final.

##  Por que isso importa?

Um banco bem construído garante que os dados do negócio fiquem **organizados, confiáveis e fáceis de consultar**, no lugar das conversas de WhatsApp e planilhas espalhadas.
